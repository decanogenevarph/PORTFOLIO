## How to publish on GitHub Pages (free)

1. Create a free account at [github.com](https://github.com).
2. Click **New repository**, name it `portfolio`, set it to **Public**, and click **Create**.
3. Click **uploading an existing file**. Drag in **everything in this folder**: all `.html` files, all `.pdf` files, and the `editable` folder. Click **Commit changes**.
4. Go to **Settings > Pages**. Under **Branch**, choose **main** and **/ (root)**, then click **Save**.
5. Wait 1 to 2 minutes. Your site will be at `https://YOUR-USERNAME.github.io/portfolio/`.

**Important:** keep all files in the same folder. The pages link to each other and to the PDFs by file name, so do not rename them.

## How to edit

**On GitHub (no software needed)**
1. Open your repository and click the file you want to change, such as `about.html`.
2. Click the **pencil icon** (Edit).
3. Press **Ctrl+F** (Cmd+F on Mac) to find the text, then type over it.
4. Click **Commit changes**. The site updates in 1 to 2 minutes.

**Tips**
- Change only the words between `>` and `<`. Leave the symbols alone so the layout does not break.
- To change colors, find the line starting with `:root{--navy:` near the top of each `.html` file. `--blue` is the teal, `--navy` is the deep blue, and `--sky` is the light blue accent. Repeat on all six pages.
- To replace a resume or project, upload a new PDF with the **same file name**.
- To add a project, copy one `<div class="proj">...</div>` block in `projects.html`, paste it below, and edit the text and file names.
- If something breaks, open the file's **History** on GitHub and restore the earlier version.
